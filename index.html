Field Manual

操作与机制

点开即用的速查。游戏在帮助打开时暂停；Esc 或点空白处关闭。

操作

左键点己方选中；再点一次取消；多选时点其中一座 = 其余向它集结
按住拖动框选所有己方建筑（含空屋/Lab）；鼠标 >6px，触屏 >8px
单击敌方/中立派出半数（向下取整，至少 1）；双击 = 全部
空格只全选孕育巢；再点一座己方塔 = 其余向它半投
E升级选中的建筑（消耗驻军，可花到 0，升完可能很脆）
1 2 3选中空屋时转化为 孕育巢 / 棘堡 / 实验室
Lab 法术槽选中 Lab → 点槽开始炼制；再点同一个槽 = 取消
释放药水炼成后单选 Lab，点敌方/中立释放（框选仍只出兵）
M / Esc静音 / 暂停；? 或 H 打开本帮助

机制速查

投送一次点击一颗光球，球上数字 = 实际派出量；在途可被棘堡拦截
转化空屋容量 10；转化只看成本，10 兵即可转棘堡/Lab（转完可能 0 兵）
Lab 炼制15s；驻军必须 ≥ 成本、期间不能出兵；被打低/冰冻/感染/攻占都会打断
冻结停机；冰层 = 冻结瞬间驻军，友方派兵 1:1 撞冰；冰不保护，仍可被攻占
感染30s 掉兵 1.5/s、停产能/停火、防御按 1；仍可出兵/升级
捕获无门槛翻转；驻军原样保留（含溢出），状态/药水清空
计分占领×10 + 升级花费×0.5 + 峰值驻军 + 时间奖励；2★ = 0.7×三星线
